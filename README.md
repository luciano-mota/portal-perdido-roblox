# As Crônicas do Portal Perdido

Jogo cooperativo de fantasia estilizada 3D para Roblox, desenvolvido pela LCM Dev Tech.

**Capítulo 1:** A Travessia · **Status:** pré-produção / desenvolvimento inicial.

O projeto será implementado em Luau, com Roblox Studio para edição visual e Rojo para sincronizar código. A campanha, nomes, personagens e cenários são conceitos originais, sem uso de propriedades intelectuais de terceiros.

## Backlog

Consulte [as issues](../../issues) (CPP-001 a CPP-029). O desenvolvimento acontece em branches e pull requests; `main` permanece estável.

## Ambiente

O Roblox Studio tem suporte oficial a Windows e macOS. Para desenvolvimento de código é possível usar VS Code e Git em outras plataformas, mas a validação visual requer o Studio.
