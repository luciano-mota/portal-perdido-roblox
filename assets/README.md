- Não adicionar arquivos binários muito grandes sem avaliar Git LFS.
- Todo arquivo efetivamente usado deve ter registro em \`docs/ASSET_MANIFEST.md\`.
- Os modelos, terrain e materiais importados pelo Roblox Studio podem exigir salvamento/exportação de lugar, armazenamento de origem e IDs da Roblox. O Rojo atual sincroniza os scripts e configs, não o conjunto completo de assets 3D.
- Não reutilizar IP de Caverna do Dragão; universo original.
